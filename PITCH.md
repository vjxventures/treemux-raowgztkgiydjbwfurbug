# ATP — Agent Trust Protocol

As AI agents begin transacting autonomously — authorizing payments, negotiating contracts, invoking APIs — there is no standardized identity layer to answer three fundamental questions: *who is this agent, what is it authorized to do, and who is liable?* ATP is the cryptographic trust infrastructure that answers all three. Built on Ed25519 keypairs and W3C DID-compatible identifiers, it provides verifiable agent credentials with delegated authority chains (org → principal → agent), fine-grained policy constraints (spending limits, rate limits, API scopes, geofencing), and a tamper-evident Merkle-chained audit log — all exposed through stateless verification APIs that resolve authorization in milliseconds. ATP targets the same inevitability that TCP/IP addressed for networking: autonomous systems need a shared trust protocol before they can safely transact, and the first credible implementation becomes embedded infrastructure with compounding switching costs.
